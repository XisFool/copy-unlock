# 安装与启用复制解锁扩展

## 概述

指导 AI 用最少的来回，协助用户在桌面 Chrome 中加载、启用并验证这个 MV3 解压扩展。凡是 `chrome://extensions` 的原生 UI（开发者模式、文件选择器、固定图标），都必须让用户自己点，AI 只给步骤和验证方法。

## 前置检查

1. 确认目标是 Chrome/Chromium 桌面浏览器，且用户能在本机操作窗口。
2. 确认扩展目录：仓库内是 `extension/`（该目录下应直接看到 `manifest.json`）。如果 `chrome://extensions` 里已有“复制解锁增强版”，沿用该卡片当前加载的路径，不要换路径或装第二份：换路径会生成新扩展 ID，站点开关和 autoCopy 设置都不会继承。
3. 先打开 `chrome://extensions` 确认是否已有“复制解锁增强版”卡片。换路径重新加载会生成新的扩展 ID，站点开关不会继承。
4. 不要索要账号密码，也不要上传/提交任何 `profile-*`、cookie 或 storage state。

## 安装步骤（逐条引导，等用户确认再下一步）

1. 让用户在地址栏输入 `chrome://extensions` 并回车。
2. 让用户打开右上角的“开发者模式”。
3. 让用户点“加载已解压的扩展程序”。
4. 让用户选择**直接包含 `manifest.json`** 的文件夹：
   - 仓库副本：`<repo>/extension`
   - 或该扩展当前已加载的路径（保持与现有安装一致，不要换路径）
   - 不要选仓库根目录或任何父目录。
5. 确认出现“复制解锁增强版”卡片（当前版本 1.0.3），开关为开，且没有“错误”按钮。
6. 建议用户点浏览器右上角拼图图标，把该扩展固定到工具栏，方便后续操作。

## 启用站点

1. 让用户打开目标实验页，例如 `https://labs.cjlu.dilabs.cn/data-analysis/index/...`，并自行登录。
2. 点工具栏的扩展图标。popup 会显示当前网站域名。
3. 点“开启复制增强”。如果已开启，按钮显示“已开启，点击关闭”。
4. 页面会自动刷新；没有刷新就让用户手动 F5。
5. 同一网站只需开启一次；换到其他网站要重复第 2–4 步。
6. 实验页 popup 里会出现“拖选自动复制”（默认勾选）；不需要它时可以取消勾选。

## 验证清单

- F12 Console 出现 `[copy-guard] active: https://labs.cjlu.dilabs.cn/...`。
- Console 执行 `window.__copyGuardInstalled === true`。
- 实验页（路径在 `/data-analysis/` 下）右下角、客服气泡上方出现“格子状态”面板；Console 执行 `document.getElementById('__cell_status_panel_host') !== null` 应返回 true。
- 复制：拖选正文后剪贴板应自动写入（无需 Ctrl+C），页面短暂提示“已复制 N 字”；也可按 Ctrl+C 兜底。
- 粘贴：点进 CodeMirror 按 Ctrl+V，确认文本进入；除非用户明确要求，否则不要运行、保存或提交。
- 自动复制只在 `/data-analysis/` 实验页生效，且不会在 CodeMirror、输入框、链接或面板上触发。
- 面板状态：`In [0]` 或空 = 未运行，`In [*]` = 运行中，`In [n]` = 成功（结果含 Traceback/Error 时为失败）；点击条目可定位格子。
- 面板标题栏可拖动，位置和折叠状态会记住；点“全部/异常”可只看失败和运行中。
- popup 显示“已开启，但本页注入未生效”时，点“修复注入并刷新”即可重新注册并刷新页面。
- 登录页、课程详情页不显示面板是正常的：面板只对 `/data-analysis/` 实验页生效，而且要求该站位已开启。

## 常见问题

- popup 显示“此页面不支持”：当前不是 http/https 页面，先打开实验页再点扩展。
- 显示“已开启”但页面没有守卫日志/面板：重载扩展会清掉动态注册。popup 现在会检测并显示“修复注入并刷新”，点一次即可；也可以用旧办法：点“已开启，点击关闭”，刷新后再点“开启复制增强”。仍不行时，检查扩展 Service Worker 的 `registerContentScripts` 报错。
- 面板不出现但复制正常：确认网站在已开启列表、URL 在 `/data-analysis/` 下、页面存在可见的 `.code-cell-wrap` 格子；隐藏或零高度的重复 CodeMirror 会被忽略。
- 拖选不自动复制：确认站点已开启、路径在 `/data-analysis/` 下、popup 的“拖选自动复制”已勾选；CodeMirror/输入框内不会自动复制。若提示“自动复制失败”，按 Ctrl+C 仍可用。
- 与其他复制扩展冲突：在 `chrome://extensions` 里禁用旧的 “Absolute Enable Right Click & Copy”，再刷新目标页。
- 扩展卡片报错：多半是选错目录（必须直接含 `manifest.json`）、文件缺失或 JSON 损坏；重新选择目录后点“重新加载”。
- 自动化测试不要依赖系统 Chrome 的 `--load-extension`（Chrome 137+ 已禁用该项）；仓库脚本使用 Playwright 自带的 Chromium 1243。

## AI 行为约束

- 一次只给一个原生 UI 操作步骤，等用户说“好了”再继续，不要一次性甩出整份清单。
- 不要尝试自动点击 `chrome://extensions`、文件选择器或开发者模式开关；这些必须由用户完成。
- 不要重复安装、不要删除用户已有扩展、不要修改扩展源码来绕过安装问题。
- 安装完成后只做用户要求的验证；只读任务中不要运行代码格、不要提交报告、不要修改实验内容。
